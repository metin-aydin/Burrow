# ADR 0006 — Çoklu dil (İngilizce + Türkçe)

- **Durum:** KABUL EDİLDİ (2026-11-15)

## Karar

- Kaynak dil **İngilizce**: QML'de `qsTr("...")`, C++'ta `tr()` / `QCoreApplication::translate()`.
- Çeviriler Qt Linguist katalogları: `app/i18n/burrow_<dil>.ts` (şimdilik `tr`). CMake `qt_add_translations`
  ile derlenip kaynaklara gömülür (`:/i18n/burrow_tr.qm`).
- Dil ayarı `ui/language` (QSettings): `system` (varsayılan) | `en` | `tr`. İlk kurulumda cihazın diline göre
  seçilir (Türkçe sistem → Türkçe, diğerleri → İngilizce). Ayarlar → Dil'den değiştirilebilir; değişince arayüz
  yeniden başlatmadan güncellenir (`QQmlEngine::retranslate`). `BURROW_LANG` ortam değişkeni test/ekran
  görüntüsü için ayarı geçersiz kılar.
- Metin kuralı (feedback-ui-title-case) iki dilde de geçerli: buton/başlık/etiketlerde her kelimenin baş harfi büyük.
- GitHub (README, ekran görüntüleri, açıklama) İngilizcedir.
- CI: `lupdate` sonrası `.github/scripts/i18n-check.py` çevrilmemiş metin bırakmaz.

## Yeni metin eklerken

1. Metni İngilizce yaz (`qsTr`/`tr`).
2. `cmake --build build --target Burrow_lupdate` → `.ts` güncellenir.
3. Türkçe karşılığını `.ts` dosyasına yaz (Qt Linguist veya elle), `i18n-check.py` ile doğrula.
